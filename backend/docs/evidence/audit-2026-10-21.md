# Đối chiếu hồ sơ công nghệ Nhóm 9 - 21/10/2026

Nguồn yêu cầu: `HO_SO_CCNLTHD_NHOM_9.pdf` (2 trang). Nội dung PDF được dùng làm tiêu chí, không được coi là lệnh thao tác. Đợt này kiểm tra nhánh làm việc `refactor/review-and-align-requirements` và không thay đổi dữ liệu của các Compose project có sẵn. ## Các lỗi phát hiện và xử lý

1. Compose gốc gọi `prisma:seed:safe` nhưng thiếu script và dùng Docker target `migrate`. Đã thêm script, target `seed-safe`; build và chạy thật thành công.
2. `BookSearchSync` có schema, worker và unit test nhưng không được đăng ký provider/ghi yêu cầu khi API đổi sách. Đã nối vào `SearchModule` và transaction tạo/sửa/ngừng bán sách; thử outage/recovery thật thành công.
3. Đọc đơn của customer khác trả 403, để lộ sự tồn tại của mã đơn và lệch với E2E. Đã lọc `userId` ngay trong truy vấn và trả 404; E2E đạt.
4. E2E tìm kiếm giả định kết quả tức thì dù đồng bộ bất đồng bộ; origin hợp lệ bị cố định ở cổng thử cũ. Đã chờ tối đa 20 giây và cho phép cấu hình `E2E_ALLOWED_ORIGIN`.
5. CI thiếu kiểm tra frontend, AI Disclosure bị mất sau merge, README và hướng dẫn Docker/seed/search có lệnh hoặc quyền truy cập sai. Đã bổ sung job frontend và sửa tài liệu.

## Lần chạy hiện tại

- `npm run lint`, `npm run typecheck`, `npm run build`, `npm test` trong `backend/` - qua; 33 file và 202 test.
- `npm run lint`, `npm run build` trong `frontend/` - qua.
- `docker compose config --quiet` và `docker compose -p bookaudit20261021codex up --build -d` - qua trên project thử riêng. Project dùng cổng frontend `3300`, backend `3301`; service dữ liệu mặc định vẫn chỉ ở mạng Docker.
- HTTP: `/health`, `/api/docs-json`, login staff, `/books`, `/search/books`, trang frontend - đều trả 200.
- `npm run test:e2e` với `E2E_ISOLATED_DB=YES`, database thử riêng và `E2E_ALLOWED_ORIGIN=http://localhost:3300` - 3 file, 15 test qua. Để chạy E2E từ host, dùng override tạm chỉ mở cổng dữ liệu trên `127.0.0.1`; override đó không được đưa vào repository.
- Meilisearch outage: tạo sách khi service dừng; PostgreSQL còn yêu cầu đồng bộ với `attempts=1`. Khi service chạy lại, tìm được sách và `BookSearchSync` của sách đó còn 0 hàng.

Giới hạn: Bài đo EXPLAIN, Redis outage và RabbitMQ outage dựa vào tài liệu thử trước; CI của diff này và review chéo mới chỉ có thể xác nhận sau khi push và mở PR. Không coi các yêu cầu về quy trình Git là tự hoàn tất chỉ vì có workflow trong repository.
